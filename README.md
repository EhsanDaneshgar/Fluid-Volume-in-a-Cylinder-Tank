# 🛢️ Fluid Volume Calculator for Horizontal Cylinder Tank (Excel Tool)

This Excel-based tool allows users to calculate the **fluid volume**, **total tank capacity**, and **percentage full** for a **horizontal cylindrical tank**. It is especially useful in industrial applications such as oil & gas, agriculture, and water storage.

Created by **Ehsan Daneshgar**  
📅 June 5, 2024

---

## 📐 How It Works

This tool estimates:
- **Tank Volume**: based on cylinder radius and length  
- **Fluid Volume**: based on the measured fill height  
- **Fill Percentage**: visual indicator of how full the tank is  

The calculation uses the geometric formula for the volume of a horizontal cylinder partially filled with fluid.

---

## 🧮 Input Fields

| Input                | Description                                   |
|---------------------|-----------------------------------------------|
| `l` (Length)         | Length of the tank (choose unit: **m** or **ft**) |
| `r` (Radius)         | Radius of the tank cross section             |
| `h` (Filled Depth)   | Height of the fluid inside the tank (m or ft)|

---

## 🧾 Output Values

| Output                    | Unit Options                           |
|---------------------------|----------------------------------------|
| **Tank Volume**           | bbl (default), m³, ft³, or liters      |
| **Fluid Volume**          | bbl, m³, ft³, or liters                |
| **% Full**                | Displayed as percentage                |
